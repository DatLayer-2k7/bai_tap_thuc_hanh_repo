# Bài Tập Thực Hành Python Journey 🐍

> Khóa học Python Journey

## 📚 Về Repository Này

Repository này dùng để:
- 📖 Ôn tập và hoàn thành các bài tập từ khóa **Python Journey**
- 💻 Thực hành lập trình Python từ cơ bản đến nâng cao
- 📊 Lưu trữ bài tập, mini-projects và capstone project
- 🚀 Theo dõi tiến độ học tập

## 🎯 Mục Tiêu

Chuẩn bị cho **kiểm tra thực hành** dựa trên yêu cầu của khóa học Python Journey:

**Sau 15 tuần, bạn có thể:**
- ✅ Viết chương trình Python đúng, rõ ràng
- ✅ Phân rã bài toán bằng hàm và module
- ✅ Chọn cấu trúc dữ liệu Python phù hợp
- ✅ Xử lý file, CSV, JSON
- ✅ Đọc traceback, debug có phương pháp
- ✅ Viết test bằng pytest
- ✅ Gọi HTTP API cơ bản
- ✅ Dùng Git/GitHub để lưu lịch sử
- ✅ Hoàn thành capstone project
